⚙️ Administrator Guide

Complete guide for managing the POS system

🏢 System Overview

As a system administrator, you have full access to all features of the POS system. Your responsibilities include:

  • User account management
  • Inventory control and stock management
  • System backup and restore operations
  • Security and access control
  • System monitoring and maintenance
  • Report generation and analysis
🔐 Security Note: With great power comes great responsibility. Always follow security best practices and maintain regular backups.

👥 User Management

Creating New Users

  1. Navigate to Users from the sidebar
  2. Click "Add New User"
  3. Fill in the user details:
    • Username: Unique identifier for the user
    • Password: Minimum 6 characters
    • Role: Admin or Cashier
  4. Click "Add User"
  5. Provide the login credentials to the new user

User Roles & Permissions

🏪 Administrator Role
  • ✅ Manage users (create, edit, delete)
  • ✅ Full inventory management
  • ✅ Process sales transactions
  • ✅ View all reports
  • ✅ System backup and restore
  • ✅ Access dashboard
💰 Cashier Role
  • ❌ Cannot manage users
  • ❌ Cannot modify inventory
  • ✅ Process sales transactions
  • ✅ View basic reports
  • ❌ Cannot backup/restore system
  • ✅ Access dashboard

Editing User Accounts

  1. Go to Users page
  2. Find the user in the list
  3. Click the Edit button
  4. Modify username, role, or password
  5. Click "Update User"

Deleting Users

⚠️ Warning: Deleting a user is permanent and cannot be undone.
  1. Go to Users page
  2. Find the user to delete
  3. Click the Delete button
  4. Confirm the deletion
  5. The user account will be permanently removed

📦 Inventory Management

Adding New Items

  1. Navigate to Inventory
  2. Click "Add New Item"
  3. Enter item details:
    • Name: Product name
    • Buying Price: Cost from supplier
    • Selling Price: Retail price
    • Quantity: Initial stock level
  4. The system will auto-generate a unique barcode
  5. Click "Add Item"

Managing Stock Levels

  • Restocking: Update quantity when new stock arrives
  • Price Updates: Modify buying/selling prices as needed
  • Low Stock Alerts: Monitor items with quantity ≤ 5
  • Out of Stock: Items with zero quantity

Bulk Operations

Use the "Add Sample Items" feature to quickly populate the inventory with common products for testing purposes.

🛡️ Backup & Restore

Creating Backups

Regular backups are crucial for data protection:

  1. Go to Backup from the sidebar
  2. Choose backup method:
    • Download Database: Immediate download of current data
    • Create Local Backup: Store backup on server
  3. Click the appropriate backup button
  4. Store backups in secure locations

Restoring from Backup

🚨 Critical Operation: Restoration will replace current data. Always create a backup before restoring.
  1. Go to Backup page
  2. Click "Restore Database"
  3. Select your backup file (.db format only)
  4. Review the warning and confirm
  5. The system will automatically backup current data
  6. Wait for restoration to complete
  7. Restart the application if prompted

Backup Best Practices

  • 📅 Schedule: Daily backups during off-peak hours
  • 💾 Storage: Multiple locations (local, external, cloud)
  • 🏷️ Naming: Use descriptive names with dates
  • ✅ Verification: Test backups periodically
  • 🔒 Security: Encrypt sensitive backup files

🔧 Advanced Troubleshooting

Common Administrative Issues

❌ Database Connection Issues

Solution: Check database file permissions, ensure file exists, restart application.

❌ User Permission Errors

Solution: Verify user roles in database, check permission assignments, restart session.

❌ Backup/Restore Failures

Solution: Check file permissions, ensure sufficient disk space, validate backup file integrity.

❌ Performance Degradation

Solution: Clear cache, optimize database, check server resources, review recent changes.

🚨 Emergency Procedures

Data Loss Recovery

  1. Stop the system to prevent further data corruption
  2. Locate recent backup from secure storage
  3. Verify backup integrity before restoration
  4. Perform restoration using backup interface
  5. Test system functionality after restore
  6. Document incident for future reference

System Compromise Response

  1. Isolate affected systems
  2. Change all passwords
  3. Review access logs
  4. Restore from clean backup
  5. Update security measures
  6. Report incident to appropriate authorities

🛡️ Security Monitor

Monitoring System Security

As an administrator, you have access to comprehensive security monitoring tools to protect your system.

Security Monitor Features

  • Real-time Statistics: Monitor login attempts for the last 24 hours and 7 days

Managing Blocked IPs

  1. Navigate to Security Monitor
  2. Review the "Currently Blocked IPs" section
  3. Check block reasons and timestamps
  4. Manually unblock IPs if needed using the unlock button
