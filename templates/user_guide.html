📚 End User Guide

Complete guide for using the POS system

🚀 Quick Start

1

Login to the System

Use your username and password provided by your administrator to log in.

2

Navigate the Dashboard

The dashboard shows your daily sales, inventory status, and quick actions.

3

Process Your First Sale

Click "Sales" to start processing customer transactions.

💰 Sales Processing

How to Process a Sale

  1. Navigate to the Sales page from the sidebar
  2. Scan or enter the barcode of the item
  3. Adjust quantity if needed using the +/- buttons
  4. Apply discount if applicable (percentage or fixed amount)
  5. Review the total and click "Complete Sale"
  6. Print receipt or provide change to customer
💡 Tip: You can search for items by name or barcode in the search bar.

📦 Inventory Management

Viewing Inventory

  • Go to Inventory from the sidebar
  • View all items with their current stock levels
  • Check low stock alerts (items with quantity ≤ 5)
  • Search for specific items using the search function

Understanding Stock Status

In Stock (Quantity > 5)
Low Stock (Quantity 1-5)
Out of Stock (Quantity = 0)

📊 Reports & Analytics

Accessing Reports

  • Click Reports in the sidebar
  • Select date range for the report
  • View sales data, profit analysis, and trends
  • Export reports if needed

Available Reports

  • Daily Sales: Today's sales performance
  • Weekly Sales: Past 7 days analysis
  • Monthly Sales: Current month overview
  • Top Products: Best-selling items
  • Low Stock Items: Items needing restocking

👤 Profile Management

Changing Your Password

  1. Go to Profile from the sidebar
  2. Click "Change Password"
  3. Enter your current password
  4. Enter your new password (minimum 6 characters)
  5. Confirm the new password
  6. Click "Update Password"

Setting Up Security Question

For password recovery, set up a security question:

  1. Go to your Profile page
  2. Find the "Security Question" section
  3. Choose a question from the dropdown
  4. Provide your answer
  5. Click "Set Security Question"

🏷️ Barcode Printing

How to Print Barcodes

  1. Go to Inventory
  2. Find the item you want to print barcode for
  3. Click the "Print Barcode" button
  4. The barcode will open in a new window
  5. Use Ctrl+P (or Cmd+P on Mac) to print
  6. Configure your printer settings as needed
💡 Tip: Make sure your printer is connected and has barcode-compatible labels loaded.

🔧 Troubleshooting

Common Issues & Solutions

❌ Can't log in to the system

Solution: Check your username and password. Contact your administrator if you forgot your password.

❌ Item not found when scanning barcode

Solution: Make sure the barcode is correct. Try searching by item name instead.

❌ Insufficient stock error

Solution: The item is out of stock. Contact your administrator to restock the item.

❌ System running slow

Solution: Clear your browser cache or try refreshing the page. Contact IT support if the issue persists.

🛡️ Security Monitor

Monitoring Login Attempts

The Security Monitor helps you track and analyze login attempts, security threats, and system access patterns.

How to Use Security Monitor

  1. Navigate to Security Monitor from the sidebar (Admin only)
  2. View real-time statistics for the last 24 hours and 7 days
  3. Monitor failed login attempts and blocked IP addresses
  4. Use advanced filters to search specific time periods or IP addresses
  5. Review recent login attempts with CAPTCHA status
  6. Export security reports for analysis

Understanding Security Metrics

  • Total Attempts: All login attempts in the time period
  • Success Rate: Percentage of successful logins
  • Failed Attempts: Number of unsuccessful login attempts
  • CAPTCHA Required: Attempts that triggered CAPTCHA verification
  • Blocked IPs: IP addresses currently blocked due to suspicious activity
💡 Security Tip: Regularly review the Security Monitor to identify potential security threats and unusual login patterns.

📋 Activity Logs

Viewing System Activity

Activity Logs provide a comprehensive record of all system activities and user actions.

How to Access Activity Logs

  1. Go to Activity Logs from the sidebar
  2. View recent activities with timestamps
  3. Filter logs by date range, user, or activity type
  4. Search for specific activities or users
  5. Export logs for compliance or auditing purposes

Types of Logged Activities

  • User Actions: Login, logout, password changes
  • Sales Activities: Transactions, refunds, discounts
  • Inventory Changes: Stock updates, new items, price changes
  • System Events: Backups, restores, configuration changes
  • Security Events: Failed logins, blocked IPs, CAPTCHA triggers

Customizing Your POS System

The Branding system allows you to customize the appearance and messaging of your POS system.

How to Update Branding

💾 Backup & Data Management

Understanding Backup Types

  • Automatic Backups: System creates backups at scheduled intervals
  • Manual Backups: Create backups on-demand
  • Database Downloads: Download current database file
  • Restore from File: Restore system from backup file

How to Create a Backup

  1. Go to Backup from the sidebar
  2. Choose "Create Database Backup"
  3. The system will create a timestamped backup file
  4. Download the backup file to a secure location
💡 Backup Tip: Store backups in multiple locations and test restoration periodically to ensure data integrity.

🔒 SSL/TLS Security

Understanding SSL/TLS

SSL/TLS encryption protects data transmission between your browser and the server.

SSL Status Indicators

  • 🔒 Secure Connection: Green lock icon indicates encrypted connection
  • ⚠️ Mixed Content: Some resources loaded without encryption
  • ❌ Not Secure: Connection is not encrypted

Security Best Practices

  • Always use HTTPS in production environments
  • Verify SSL certificate validity
  • Keep SSL certificates updated
  • Use strong encryption protocols (TLS 1.2 or higher)
