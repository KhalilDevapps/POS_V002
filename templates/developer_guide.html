🏗️ System Architecture

🗄️ Database Schema

Core Tables

users Table
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username VARCHAR(80) UNIQUE NOT NULL,
    password_hash VARCHAR(128) NOT NULL,
    role VARCHAR(20) NOT NULL,
    secret_question VARCHAR(200),
    secret_answer VARCHAR(200),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

Indexes: username (unique), role

Relationships: One-to-many with sales table

items Table
CREATE TABLE items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(100) NOT NULL,
    buying_price FLOAT NOT NULL,
    selling_price FLOAT NOT NULL,
    quantity INTEGER NOT NULL,
    barcode VARCHAR(50) UNIQUE NOT NULL,
    sold_quantity INTEGER DEFAULT 0,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

Indexes: barcode (unique), name

Relationships: One-to-many with sale_items table

sales Table
CREATE TABLE sales (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    total_amount FLOAT NOT NULL,
    discount_percent FLOAT DEFAULT 0,
    discount_amount FLOAT DEFAULT 0,
    final_amount FLOAT NOT NULL,
    profit FLOAT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

Indexes: user_id, created_at

Relationships: Belongs to users, has many sale_items

sale_items Table
CREATE TABLE sale_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    sale_id INTEGER NOT NULL,
    item_id INTEGER NOT NULL,
    quantity INTEGER NOT NULL,
    unit_price FLOAT NOT NULL,
    total_price FLOAT NOT NULL,
    FOREIGN KEY (sale_id) REFERENCES sales(id),
    FOREIGN KEY (item_id) REFERENCES items(id)
);

Indexes: sale_id, item_id

Relationships: Belongs to sales and items

🚀 Installation & Setup

Prerequisites

  • Python 3.8 or higher
  • pip package manager
  • Git (for cloning repository)
  • Modern web browser

Installation Steps

# 1. Clone the repository
git clone https://github.com/your-org/pos-system.git
cd pos-system

# 2. Create virtual environment
python -m venv venv

# 3. Activate virtual environment
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 4. Install dependencies
pip install -r requirements.txt

# 5. Set up environment variables
cp .env.example .env
# Edit .env with your configuration

# 6. Initialize database
python app.py

# The application will start on http://localhost:5000

Environment Configuration

# .env file configuration
SECRET_KEY=your-super-secret-key-here
DATABASE_URL=sqlite:///pos.db
DEBUG=True
HOST=0.0.0.0
PORT=5000
SESSION_TIMEOUT=3600

🔒 Security Guidelines

Authentication & Authorization

Password Security
  • Use Werkzeug for password hashing (PBKDF2)
  • Minimum password length: 6 characters
  • Implement password strength requirements
  • Force password changes periodically
  • Store passwords securely (never in plain text)
Session Management
  • Use secure session cookies
  • Implement session timeout
  • Regenerate session ID on login
  • Store session data securely
  • Clear session on logout

Data Protection

  • Use parameterized queries to prevent SQL injection
  • Validate and sanitize all user inputs
  • Implement CSRF protection
  • Use HTTPS in production
  • Regular security audits and updates

File Upload Security

  • Validate file types and extensions
  • Check file size limits
  • Scan uploaded files for malware
  • Store files outside web root
  • Use secure file permissions

🔧 Developer Troubleshooting

Common Development Issues

❌ Database Connection Errors
Problem: Unable to connect to database
Solution:
  • Check database file permissions
  • Verify DATABASE_URL in .env file
  • Ensure SQLite file exists
  • Check file system permissions
❌ Template Not Found Errors
Problem: Jinja2 template errors
Solution:
  • Verify template file exists in templates/ directory
  • Check template file permissions
  • Ensure correct template name in render_template()
  • Check for syntax errors in template
❌ Static File Loading Issues
Problem: CSS/JS files not loading
Solution:
  • Verify files exist in static/ directory
  • Check file permissions
  • Ensure correct URL paths in templates
  • Clear browser cache
❌ Permission Denied Errors
Problem: Access denied to certain features
Solution:
  • Check user role assignments
  • Verify permission decorators
  • Review ROLE_PERMISSIONS configuration
  • Test with admin account

🔒 SSL/TLS Configuration

SSL/TLS Setup for Production

Certificate Installation

# 1. Obtain SSL certificate files
certificate.crt
private.key
intermediate.crt (if provided)

# 2. Configure Flask for HTTPS
from flask_sslify import SSLify

app = Flask(__name__)
sslify = SSLify(app)

if __name__ == '__main__':
    context = ssl.SSLContext(ssl.PROTOCOL_TLSv1_2)
    context.load_cert_chain('certificate.crt', 'private.key')
    app.run(host='0.0.0.0', port=443, ssl_context=context)

Nginx SSL Configuration

server {
    listen 443 ssl http2;
    server_name yourdomain.com;

    ssl_certificate /path/to/certificate.crt;
    ssl_certificate_key /path/to/private.key;
    ssl_trusted_certificate /path/to/intermediate.crt;

    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512;
    ssl_prefer_server_ciphers off;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}

Enhanced Search Implementation

# Advanced search with filters
@app.route('/api/search')
def advanced_search():
    query = request.args.get('q', '')
    category = request.args.get('category')
    min_price = request.args.get('min_price')
    max_price = request.args.get('max_price')

    items = Item.query

    if query:
        items = items.filter(Item.name.contains(query))

    if category:
        items = items.filter(Item.category_id == category)

    if min_price:
        items = items.filter(Item.selling_price >= float(min_price))

    if max_price:
        items = items.filter(Item.selling_price <= float(max_price))

    return jsonify([item.to_dict() for item in items.all()])

Data Export Features

# Export data in multiple formats
@app.route('/api/export/')
def export_data(format):
    data_type = request.args.get('type', 'inventory')

    if data_type == 'inventory':
        items = Item.query.all()
        data = [item.to_dict() for item in items]
    elif data_type == 'sales':
        sales = Sale.query.all()
        data = [sale.to_dict() for sale in sales]

    if format == 'csv':
        return export_csv(data, f'{data_type}.csv')
    elif format == 'json':
        return jsonify(data)
    elif format == 'xml':
        return export_xml(data, f'{data_type}.xml')

/* Swipe gestures for mobile */
let touchStartX = 0;
let touchEndX = 0;

document.addEventListener('touchstart', e => {
    touchStartX = e.changedTouches[0].screenX;
});

document.addEventListener('touchend', e => {
    touchEndX = e.changedTouches[0].screenX;
    handleSwipe();
});

function handleSwipe() {
    const swipeThreshold = 50;
    if (touchEndX < touchStartX - swipeThreshold) {
        // Swipe left - next item
        showNextItem();
    }
    if (touchEndX > touchStartX + swipeThreshold) {
        // Swipe right - previous item
        showPreviousItem();
    }
}
